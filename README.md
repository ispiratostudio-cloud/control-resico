# Control RESICO — sitio público

Calculadora gratuita de ISR RESICO 2026 y página de venta del kit **Control RESICO 2026**.
Se publica automáticamente en GitHub Pages con cada push a `main`.

- `index.html`: página de venta y calculadora.
- `tabla-resico-2026.html`: artículo SEO.
- `config.js`: enlaces de compra (Payhip). Vacíos = botón "Próximamente".
